## Description

Create an educational visualizer for the quantized free string's oscillator modes and physical-state constraints. It should teach the distinction between a classical profile and a quantum state, without claiming to numerically solve non-perturbative or interacting string theory.

## Subtasks

### T19a: Fix the pedagogical scope
- Choose bosonic closed strings in flat space as the first narrow presentation, or record another approved scope.
- Explain oscillator modes, level number, left/right movers, and the physical-state condition at an appropriate level.

### T19b: Design a finite state representation
- Define a bounded occupation-number/state selector rather than an unbounded Hilbert-space calculation.
- Include normalization and truncation warnings in the UI and documentation.

### T19c: Build the visual and explanatory layer
- Visualize selected oscillator occupations, level matching, and illustrative target-space profiles separately from probability/state information.
- Add glossary, guided-learning, and accessibility coverage.

### T19d: Verify mathematical and communication accuracy
- Check displayed spectra and level-matching examples against the documented convention.
- Review every label to distinguish a state visualizer from dynamical quantum evolution.

## Acceptance Criteria
- [ ] The selected theory, dimension/convention, and finite truncation are declared before implementation.
- [ ] State selection enforces or visibly flags invalid level-matching/physical-state examples.
- [ ] Examples explain the difference between a classical shape, an oscillator state, and a quantum measurement prediction.
- [ ] Formulae, labels, and documentation receive an accuracy review against the stated convention.
- [ ] No feature claims to simulate string interactions or a general quantum-string solution.
