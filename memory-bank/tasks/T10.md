### T10a: Canvas Resize Transform Accumulation
**File**: `src/visualization/renderer.ts`, `src/visualization/worldsheet.ts`

**Bug**: Both renderers call `this.ctx.scale(this.dpr, this.dpr)` every time the canvas is resized. Without resetting the transform first, repeated browser resizing compounds the scale.

**Fix**: At the start of each `handleResize()`:
```typescript
this.ctx.setTransform(1, 0, 0, 1, 0, 0);
// then set width/height, then:
this.ctx.scale(this.dpr, this.dpr);
```

**Acceptance**: Resize the browser window 10 times; canvas content remains at correct scale.

### T10b: Causal Rays in Data Space (not Pixel Space)
**File**: `src/visualization/worldsheet.ts`

**Bug**: `drawLightConeBoundaries()` constructs lines with fixed 45° pixel slope. This is physically wrong when one pixel in the horizontal direction and one pixel in the vertical direction represent different physical coordinate intervals.

**Fix**: Compute endpoints in `(σ, τ)` data coordinates:
```typescript
// From source point (sigma0, tau0)
const tauEnd = this.tauMax; // or tauMin for lower rays
const sigmaRight = sigma0 + (tauEnd - tau0); // +1 slope in data space
const sigmaLeft = sigma0 - (tauEnd - tau0);  // -1 slope in data space

// Map through mapSigma() and mapTau()
const x0 = this.mapSigma(sigma0);
const y0 = this.mapTau(tau0);
const xR = this.mapSigma(sigmaRight);
const yE = this.mapTau(tauEnd);
// ... draw lines
```

**Acceptance**: Light cone boundaries have slope ±1 in `(σ, τ)` data space regardless of canvas aspect ratio.

### T10c: History Timestamp Off-by-One
**File**: `src/physics/relativistic.ts`

**Bug**: `history.push(y)` stores the pre-step profile, but the reconstruction formula `state.t - (history.length - 1 - h) * dt` labels every profile one `Δτ` too late.

**Example**:
- Step 0: push `y` at `t=0`, then `state.t` becomes `Δτ`. Reconstruction: `t = Δτ - 0 = Δτ` (wrong, should be 0).

**Fix**: Change reconstruction to:
```typescript
const t = this.state.t - (history.length - h) * this.config.dt;
//                                          ^ removed the "- 1"
```

Alternatively, store `{ t, y }` objects for clarity:
```typescript
interface HistorySample {
  t: number;
  y: Float64Array;
}
this.history.push({ t: this.state.t, y: new Float64Array(y) });
```

**Acceptance**: With a paused initial state, the worldsheet shows the initial profile at `τ = 0`, not `τ = Δτ`.
