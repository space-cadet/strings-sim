## Overview

Rebuild the simulator as a **linked three-view instrument** instead of two largely independent plots. This is the central architectural change from Terra's review and matches Deepak's mockups.

The three views are:
1. **Live Profile**: `y(σ, τ₀)` — the string's current shape (primary, largest)
2. **Worldsheet**: `y(σ, τ)` as `(σ, τ)` heatmap — evolution of the entire string
3. **Probe Trajectory**: `y(τ; σ*)` — motion of one labelled point on the string

## Visual Layout

### Desktop (~65/35 split)

```
┌─────────────────────────────────────┬──────────────────┐
│  y(σ, τ₀) — String Profile          │  Controls        │
│  (largest panel)                     │  - Presets       │
│                                      │  - Boundary      │
│  [Energy strip ℰ(σ,τ₀)]             │  - Parameters    │
│                                      │  - Playback      │
├─────────────────────────────────────┤                  │
│  Worldsheet y(σ,τ)                  │  - Mode toggle   │
│  (σ horizontal, τ vertical)          │                  │
│  ~2.5:1 aspect ratio                │  Metrics         │
│                                      │  - E, E_kin, E_p │
├─────────────────────────────────────┤  - Courant #     │
│  Probe Trajectory y(τ;σ*)           │  - Max |ẏ|       │
│  (compact, collapsible)              │                  │
└─────────────────────────────────────┴──────────────────┘
```

### Mobile (stacked)

1. Current profile `y(σ, τ₀)`
2. Playback controls (thin strip, non-overlapping)
3. Compact mode/preset strip
4. Worldsheet `y(σ, τ)`
5. Probe trajectory `y(τ; σ*)`
6. Expandable physics controls and diagnostics

## Key Design Decisions

- **Probe trajectory is secondary**: compact, collapsible by default, appears after a probe is selected
- **Worldsheet is wider than tall**: ~2.5:1 aspect ratio, shows fixed temporal window (e.g. last `5L` or `10L` in natural units)
- **Instantaneous profile is largest**: it's the visual object users manipulate and immediately recognize
- **No overlay of large controls across plot area**

## Implementation Tasks

2. **Panel visibility system**: Collapsible/expandable probe trajectory
3. **Aspect ratio enforcement**: Worldsheet container maintains ~2.5:1
4. **Responsive breakpoints**: Desktop ↔ mobile layout switch
