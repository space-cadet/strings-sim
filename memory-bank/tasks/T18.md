## Description

Add a separately labelled classical relativistic-string mode that evolves a full embedding $X^\mu(\sigma,\tau)$ in flat Minkowski spacetime. It must retain the gauge and constraint conditions that make the numerical result physically meaningful. This is not a quantum or interacting-string implementation.

## Implementation Details

The implementation uses conformal gauge with $X^0=\tau$ in flat 2+1-dimensional Minkowski spacetime, natural units, and unit tension/density. Periodic runs use a closed loop with $\Delta\sigma=L/N$; fixed, free, and mixed runs use reflected characteristic fields on an open interval with $\Delta\sigma=L/(N-1)$. It transports left- and right-moving unit tangent fields with a Courant number of 0.5 and projects interpolated tangents back to unit length. The pointwise constraints are $\partial_\tau X\cdot\partial_\sigma X=0$ and $(\partial_\tau X)^2+(\partial_\sigma X)^2=1$ for the spatial embedding. Open runs report endpoint-condition residuals and boundary energy flux; periodic runs report closure separately. Treat numerical constraint preservation as a release gate, not a cosmetic metric. Anti-periodic/twisted data and UI exposure remain unvalidated.
