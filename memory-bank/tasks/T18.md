## Description

Add a separately labelled classical relativistic-string mode that evolves a full embedding $X^\mu(\sigma,\tau)$ in flat Minkowski spacetime. It must retain the gauge and constraint conditions that make the numerical result physically meaningful. This is not a quantum or interacting-string implementation.

## Subtasks

### T18a: Specify formulation and data contract
- Select conformal gauge or static gauge and document the target-space dimension, units, metric, and open/closed-string support.
- Define constraint-satisfying initial data for $X^\mu$ and its time derivative.

### T18b: Implement constraint-preserving evolution
- Build a nonlinear numerical integrator with stable spatial derivatives and timestep control.
- Add constraint residual monitoring and a clear response when a run leaves tolerance.

### T18c: Implement boundaries and observables
- Support closed periodic strings first; add open Neumann/Dirichlet endpoints only after their constraints and energy flux are verified.
- Render embedding projections and worldsheet diagnostics without conflating them with the T17 profile view.

### T18d: Validate nonlinear behaviour
- Test convergence under grid and timestep refinement.
- Compare the small-amplitude limit against T17, and demonstrate nonlinear mode coupling with a documented initial state.

## Implementation Details

Prefer a staged conformal-gauge implementation because it makes the constraints explicit. Treat numerical constraint preservation as a release gate, not a cosmetic metric. Do not infer chaos from visual complexity; use a nearby-trajectory comparison and finite-time Lyapunov estimate only after the nonlinear solver is validated.
