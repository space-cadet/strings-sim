## Description

Create a conceptual, explicitly non-dynamical visualization of perturbative string splitting and joining as worldsheet topology. It should show why interactions are commonly represented by a sum over worldsheets, not by an unsupported deterministic local splitting rule in the current simulator.

## Subtasks

### T20a: Define the claims and non-claims
- Specify which tree-level process is illustrated and what the visualization does not calculate.
- Obtain review of terminology for topology, genus, coupling, and amplitudes.

### T20b: Build static and navigable worldsheet diagrams
- Provide accessible diagrams for propagation, splitting/joining, and an optional loop/topology comparison.
- Use ordinary links and text alternatives; do not hide essential meaning in animation.

### T20c: Connect to the free-string visualizer
- Map the diagram to in/out free-string states from T19 where pedagogically appropriate.
- Explain that no scattering amplitude is computed unless a separately scoped calculation is added.

### T20d: Validate presentation boundaries
- Verify labels, formulae, and screen-reader descriptions.
- Confirm that no UI wording claims a simulated general interaction or non-perturbative result.

## Acceptance Criteria
- [ ] Every diagram is labelled as conceptual/perturbative and identifies its topology/process.
- [ ] Text alternatives explain the event without requiring a visual animation.
- [ ] Documentation distinguishes a topology illustration from an amplitude calculation.
- [ ] Links to T19 examples preserve the free-state versus interaction distinction.
- [ ] A physics-content review accepts the claims and caveats.
