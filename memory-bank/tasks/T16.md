## Description

Make the simulator a visual guide to learning string theory by adding a full, accurate mathematical glossary and contextual help. Each relevant GUI label receives a compact question-mark icon: hover or keyboard focus shows a brief explanation, and activation opens the corresponding stable section of the site's detailed documentation.

The documentation must describe the model and numerical implementation that the application actually runs. It must clearly distinguish the classical and linearized relativistic teaching models from a full quantum, interacting string-theory calculation.

## Implementation Details

1. Add a typed registry, proposed at `src/content/glossary.ts`, with a stable ID, display name, symbol, short tooltip, detailed explanation, formula, implementation note, related entries, and caveats for each concept.
2. Add Vite multipage entries for `learn/index.html`, `glossary/index.html`, and `implementation/index.html`, while keeping the Simulator at `index.html`. The deployed routes are `/projects/strings-sim/`, `/learn/`, `/glossary/`, and `/implementation/`.
3. Add a reusable help-link pattern that is a real anchor, not hover-only UI. It must expose a descriptive accessible name, reveal a short tooltip on pointer hover and keyboard focus, and go directly to the detail section on click or tap.
4. Map all current interface elements first, then add entries as T12 probe and T13 diagnostic/field-selector controls are implemented.
5. Give every page the same ordinary-link tab navigation. The active tab is conveyed visually and semantically; this is not a JavaScript-only tab widget.
6. Make Learn a sequence of short guided experiments: physical picture, wave propagation/reflection/interference, normal modes, boundary conditions, worldsheets, and the probe trajectory. Use $...$ and $$...$$ for mathematics in Markdown source files.
