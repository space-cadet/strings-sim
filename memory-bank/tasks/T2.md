## Details

Implement the non-relativistic string physics solver:
- 1D wave equation: ∂²y/∂t² = c² ∂²y/∂x² - γ ∂y/∂t
- Finite difference method with Verlet-like time stepping
- Boundary conditions: fixed, free, mixed
- Energy computation: kinetic + potential
