## Overview

Add a **draggable probe point** on the string profile that tracks a fixed `σ*` position. Its history is plotted as `y(τ; σ*)` — a proper graph with `τ` horizontal and `y` vertical. This replaces the current "Relativistic History" panel which is actually a compressed and misleading trace.

## Features

### 1. Draggable Probe on Profile
- A cyan dot on the `y(σ, τ₀)` profile at the selected `σ*`
- Click or drag on the profile to move `σ*`
- Color identifies the same point across all three views

### 2. Probe Trajectory Panel
- Horizontal axis: `τ` (time), rolling window matched to worldsheet
- Vertical axis: `y(σ*, τ)`
- One vivid trace for the selected probe point
- Optional faint traces for two additional pinned probes
- Small horizontal line at `y = 0`
- Optional: `|dy/dτ| = 1` diagonal guide, clearly labeled

### 3. Worldsheet Linkage
- Thin vertical line at `σ = σ*` in the worldsheet heatmap
- The selected worldline is highlighted
- Clicking on the worldsheet sets `σ*`

### 4. Trajectory History Buffer
- Store `y[probeIndex]` at each time step
- Rolling buffer matched to worldsheet temporal window
- Decouple from full worldsheet history (the probe needs only one scalar per timestep)
